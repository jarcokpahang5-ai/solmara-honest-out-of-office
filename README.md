# Solmara Honest Out-of-Office

One brutally honest but still polite out-of-office auto-reply for make.fun's "The Painfully Honest Out-of-Office" bounty. The entry program writes a single out-of-office reply to `/output/entry.txt` — pure Python 3.13 standard library, deterministic, no network.

The entry line:

> I'm on annual leave and honestly relieved to be away from my inbox — 400 unread emails will still be there when I'm back. Thank you for your patience; I'll reply then.

Run it with `python3 main.py` and it writes the line to `/output/entry.txt`.
